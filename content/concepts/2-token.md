# Token（词元）

> 就像量布匹用"米"、量鸡蛋用"个"，AI 处理文字用的计量单位叫 Token——官方中文译名是"词元"。

Token 是 AI 处理文字时的最小单位。AI 并不像人一样一个字一个字地读，而是把文本切成一块块小片段，每块就是一个 Token——可能是半个英文单词、一个汉字，或者一个标点符号，具体怎么切取决于 AI 模型。你发的每条消息、AI 给的每段回复，都在被换算成 Token 数量——这是大部分 AI 服务计费的依据。

举个例子：以 OpenAI 为参考，1000 个 Token 大约能处理 500 个中文汉字或 750 个英文单词。和 AI 进行一次日常对话（一问一答），大约消耗几十到几百个 Token。像 ChatGPT 这样的服务按 Token 收费，免费额度用完就需要付费。Token 还决定了 AI 的"记忆上限"——超过一定数量，AI 就会"忘掉"对话的开头。

理解 Token，你就能更聪明地使用 AI：说话更精炼，省 Token，也省钱。

💡 小贴士：1000 个 Token ≈ 500 汉字或 750 英文单词（OpenAI 官方数据）。
