# LLM（大语言模型）

> 想象一个学生，把互联网上几乎所有的书籍、文章、聊天记录都读了一遍，然后你随时可以和他对话——这就是大语言模型（LLM）。

LLM 是 Large Language Model 的缩写，是 ChatGPT、Claude、DeepSeek 这些 AI 助手背后的核心引擎。它通过分析几千亿条人类写过的文字，学会了理解问题并生成流畅的回答。但它不是真的在"思考"，而是在做极其精妙的"文字概率预测"——根据上下文，猜出下一个最合适的词。

举个例子：你问 LLM"我奶奶生日快到了，帮我写张贺卡"，它并不是去查什么数据库，而是从它读过的亿万篇文章里提炼出"贺卡应该温暖、简短、充满祝福"的模式，然后为你生成一段量身定制的文字。这个能力让它在写作、翻译、问答上表现惊艳。

理解 LLM 的本质很重要：它擅长"流畅"，不等于擅长"准确"——有时它会一本正经地说错事，这就是后面会讲到的"幻觉"问题的来源。

💡 小贴士：全球主流 LLM 参数量超千亿，相当于读了几十个图书馆。
