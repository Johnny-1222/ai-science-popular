# Agent（智能体）

> 如果说普通 AI 是一个只会回答问题的客服，Agent 就是一个拿到任务后能自己想办法、自己动手把事情办完的员工。

Agent（智能体）是 AI 的升级版形态。普通 AI 只能"聊天"——你问它一个问题，它回答一个结果。而 Agent 能"行动"：它可以自己分解任务、调用工具（搜索网页、发邮件、操作文件），在没有人全程盯着的情况下，一步一步把复杂的事情做完。

举个例子：你告诉 Agent"帮我规划下周去杭州的两天行程，查好天气、找好酒店、列出必去景点"，它不会给你一段文字建议——它会真的去搜索天气、对比酒店价格、抓取景点信息，最后给你一份可直接使用的行程表。2026 年，Agent 正在从开发者工具走进普通人的工作流，"养虾""养马"这些流行语背后，就是 Agent 浪潮。

你在这个网站读到的"养虾"和"养马"，就是两种具体的 Agent 产品。

💡 小贴士：Agent = AI 大脑 + 工具调用能力 + 自主行动能力，三者缺一不可。
